# Tipos de proyecto

Cada tipo es una receta corta: **base + qué módulos + estructura por
defecto** (la que se propone en la fase [02](../fases/02-estructura.md)
cuando el cliente no la da) + lo específico de ese tipo.

| Tipo | Módulos | Ejemplos |
| --- | --- | --- |
| [Landing corporativa](landing.md) | (Multimedia) | clays-of-the-world, magnaceramica |
| [Landing internacional](landing-internacional.md) | Idiomas + Migración | xanatechnologies |
| [Web de producto](web-producto.md) | Multipágina + Formulario avanzado (+ Movimiento) | xanasystem-web |
| [Web editorial / de servicios](web-editorial.md) | Multipágina + Blog | APC-gestion-patrimonial |
| [Web de evento](web-evento.md) | Evento + Multimedia | festival-viento |

Si un proyecto no encaja en ninguno: base + los módulos que toquen.
