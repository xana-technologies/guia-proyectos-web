# Plantillas

Ficheros listos para copiar a un proyecto. Claude los prepara en el arranque
(y en la fase que toque) según la base y los módulos del proyecto. El formato
de los documentos para el cliente da igual (Word, PDF, formulario): lo que
importa es qué se pide.

| Carpeta | Para quién | Qué hay |
| --- | --- | --- |
| [`cliente/`](cliente/README.md) | Cliente | Cuestionario de arranque, datos legales, formulario, accesos, material, instrucciones DNS, entrega |
| [`equipo/`](equipo/README.md) | Eva, ingeniería | Petición de SEO, alta de formulario |
| [`proyecto/`](proyecto/README.md) | Claude, Belén | `CLAUDE.md`, `CHECKLIST.md`, estructura de `docs/`, inventario de imágenes, búsqueda de stock, referencias |
| [`legales/`](legales/README.md) | Web | Texto base de aviso legal, privacidad y cookies (ES/EN), variables, párrafos por módulo |
| [`codigo/`](codigo/README.md) | Web | Qué trae el repo plantilla y, mientras no existe, de dónde se copia cada pieza |
