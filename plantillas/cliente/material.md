# Material para la web

*Plantilla para el cliente. Se envía en el arranque y se recuerda al cerrar
los contenidos (fase 03).*

---

Estas son las cosas que nos ayudan a hacer la web. Envía lo que tengas; lo
que falte lo resolvemos contigo.

## 1. Logotipo

- En **SVG** (formato vectorial) si es posible. Si no, en PNG con fondo
  transparente y el mayor tamaño que tengas.
- Todas las versiones que tengáis: horizontal, vertical, solo símbolo, en
  blanco para fondos oscuros.

## 2. Manual de marca *(si existe)*

PDF con colores, tipografías y normas de uso del logo.

## 3. Fotografías

- Instalaciones, equipo, producto, proyectos realizados…
- **Originales**, sin comprimir ni enviar por WhatsApp (pierden calidad).
- Indica si alguna **no se puede usar** o necesita citar autor.
- Si no tenéis fotos de algo, lo decimos y buscamos imágenes de banco.

## 4. Vídeos *(opcional)*

Archivos originales o enlace de descarga. Indica si se pueden usar en la web
tal cual o si hay alguno solo para uso interno.

## 5. Textos

- Textos que ya tengáis: web actual, catálogo, presentación, dossier.
- Datos concretos que queráis destacar: años de experiencia, cifras,
  certificaciones, clientes. **Solo publicamos datos que nos confirméis.**

## Cómo enviarlo

Por enlace de descarga (Drive, WeTransfer…) para archivos pesados.
