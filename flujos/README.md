# Flujos

Las tareas que se repiten en todos los proyectos, paso a paso. Claude los
conoce y los aplica sin que haya que explicarlos otra vez. Más adelante, cada
flujo será una skill.

## Estructura fija de cada flujo

1. **Cuándo se usa**: en qué fase y ante qué situación.
2. **Qué tenemos**: escenarios según lo que mande el cliente.
3. **Pasos y quién**: Claude, Belén, cliente, Eva o ingeniería.
4. **Plantillas**: qué se entrega o se copia (`../plantillas/`).
5. **Dónde queda cada cosa**: carpetas y nombres.
6. **Reglas y trampas.**
7. **Checklist.**
