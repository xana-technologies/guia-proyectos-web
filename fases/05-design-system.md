# 05 · Design system

**Qué es.** Convertir la marca en piezas reutilizables de la web. Si el
cliente trae Figma, el sistema se saca de ese Figma.

**Necesita antes.** 04.

## Qué se hace

1. **Referencias visuales**: las hace siempre Belén, salvo que el cliente las
   ponga en el briefing. Claude las ordena y anota qué se toma de cada una.
2. **Tokens**: colores, tipografía, espacios, radios, duraciones, con el
   contraste comprobado.
3. **Componentes**: botón, logo, sección, cabecera de sección…
4. **Moldes**: los tipos de sección que se repiten.
5. **Styleguide**: página interna, fuera de Google, con todas las piezas.

## Quién

Belén decide; Claude programa.

## Qué queda hecho

`docs/05-referencias-visuales/`, `src/styles/tokens.css`, componentes y `/styleguide`.
