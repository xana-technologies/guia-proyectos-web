# 03 · Contenidos y SEO

**Qué es.** Los textos de la web, escritos a partir de lo que la gente busca.

**Necesita antes.** 02.

## Escenarios

| | Qué se hace |
| --- | --- |
| 🟢 Copy cerrado | Se usa literal |
| 🟡 Textos sueltos o de la web antigua | Se reordenan y adaptan; lo que falta, `[[ ]]` |
| 🔴 No hay textos | Claude los escribe con los datos que haya, **sin inventar cifras ni hechos** |

## Qué se hace

1. Palabras clave por página o sección: las manda Eva
   ([qué tiene que mandar](../plantillas/equipo/README.md)).
2. Copy con el tono de la marca.
3. Título y descripción de cada página.
4. **Cierre del inventario**: qué imagen va en cada sitio, cuáles faltan y si
   se buscan en Magnific o se generan con IA.

## Quién

Eva manda el SEO, Claude escribe o adapta, Belén revisa, el cliente aprueba.

## Qué queda hecho

`docs/03-contenidos/` (copy por página, metadatos SEO) e inventario de
imágenes cerrado.
