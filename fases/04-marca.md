# 04 · Marca

**Qué es.** Tener clara la identidad del cliente para aplicarla en web.

**Necesita antes.** 00.

## Escenarios

| | Qué se hace |
| --- | --- |
| 🟢 Hay manual | Se traduce a decisiones de web en `brand/README.md` (contraste en pantalla, logo sobre foto…) |
| 🟡 Solo logo y colores | Se completa: tipografías, estilo de fotografía, tono |
| 🔴 No hay nada | **Brand board**: logo y usos, paleta, tipografías, fotografía, iconos, tono, ejemplos aplicados |
