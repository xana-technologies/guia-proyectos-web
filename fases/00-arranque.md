# 00 · Arranque

**Qué es.** El punto de partida: saber qué quiere el cliente, qué nos trae y qué
falta, para decidir qué fases hacemos nosotros.

**Necesita antes.** Nada.

## Qué se hace

- Leer el briefing: tipo de proyecto ([`../tipos-de-proyecto/`](../tipos-de-proyecto/README.md))
  y módulos que lleva ([`../modulos/`](../modulos/README.md)).
- Ver qué trae el cliente (investigación, estructura, textos, manual, diseño,
  fotos, vídeos) → qué escenario 🟢🟡🔴 toca en cada fase.
- **¿Tiene web antigua?** Si la tiene, inventario de sus URLs para las
  redirecciones → módulo [migración](../modulos/migracion.md).
- **Inventario inicial de material**: imágenes, vídeos, logos; qué hay y qué falta.
- **Accesos del cliente**: dominio (DonDominio u otro), Google Search Console,
  Tag Manager y Analytics.
- **Cuentas internas**: equipo de Vercel, organización de GitHub, usuario y
  clave SSH con los que se trabaja.
- Pedir los datos del cliente para legales y formulario.

## Quién

Claude monta el kit de arranque. Belén revisa y envía al cliente lo necesario.

## Qué queda hecho

- Proyecto creado desde el repo plantilla, con `CLAUDE.md` y `CHECKLIST.md`.
- `docs/` con la estructura por fases.
- Plantillas para el cliente: datos legales, correos del formulario, accesos, material.
- Inventario de material empezado.
